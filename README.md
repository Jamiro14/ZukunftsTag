# 🚀 CodeLab – Zukunftstag

Kinder (8–12) programmieren Schritt für Schritt ihre eigene Webseite:
Sie starten mit einer langweiligen Seite, wählen links ein Design, kopieren den CSS-Code
und fügen ihn unten ins Code-Feld ein. Der Code wird wirklich vom Browser angewendet und geprüft.

- `index.html` – Aufbau
- `app.css` – Aussehen vom CodeLab
- `schritte.js` – **die 10 Schritte & Designs (hier anpassen)**
- `css-leser.js` – liest den Code, findet Fehler, prüft Schritte
- `app.js` – Steuerung, Speichern, Vorschau

Gespeichert wird im Browser (localStorage) pro Laptop. Hosting: GitHub Pages (main, / root).
