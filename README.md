# 🚀 CodeLab – Zukunftstag & Triebwerk

Beim Start wählen die Teilnehmenden einen von zwei Workshops:

- **Zukunftstag**: Kinder (8–12) gestalten Schritt für Schritt ihre persönliche Webseite. Sie wählen Designs, übernehmen CSS und sehen das Ergebnis live.
- **Triebwerk**: Jugendliche ab etwa 14 gestalten in einer rund 40-minütigen Challenge einen vorbereiteten HTML/CSS-Entwurf. 14 kleine Aufgaben erklären die Grundlagen ohne Vorkenntnisse; optionale Bonus-Missionen bieten Ausbaupotenzial.

- `index.html` – Aufbau
- `app.css` – Aussehen von Auswahl und Workshops
- `schritte.js` – **die 10 Schritte & Designs (hier anpassen)**
- `css-leser.js` – liest den Code, findet Fehler, prüft Schritte
- `app.js` – Zukunftstag-Steuerung, Speichern und Vorschau
- `triebwerk.js` – Triebwerk-Aufgaben, HTML/CSS-Prüfung, Autoformatierung, Live-Vorschau und lokaler Spielstand

Gespeichert wird im Browser (localStorage) pro Laptop. Hosting: GitHub Pages (main, / root).
